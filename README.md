# Автодокументация JS файлов

Проект для автоматической генерации документации из JavaScript файлов в формате Word (.docx) на основе JSDoc комментариев.

## Описание

Инструмент анализирует JavaScript файлы в указанной директории, извлекает JSDoc комментарии и создает структурированную документацию в формате Word.

## Запуск

### Предварительные требования

- Node.js

### Установка

`` make all `` - устанавливает зависимости и генерирует документацию из папки game

`` make install `` - устанавливает зависимости

`` make docs `` - генерирует документацию
